# Agilex 7 FPGA M-Series Development Kit - HBM2e Edition (DK-DEV-AGM039FES)

Platform folder `dk-dev-agm039fes-oobe` contains designs for the Agilex 7 FPGA M-Series Development Kit - HBM2e Edition DK-DEV-AGM039FES (DDR5 configuration).

Refer to the [HPS Baseline System Example Design User Guide: Agilex 7 M-Series HBM2e Development Kit](https://altera-fpga.github.io/latest/embedded-designs/agilex-7/m-series/hbm2e/ug-gsrd-agx7m-hbm2e/) for more information.

## Designs

| Design | Description |
|--------|-------------|
| [baseline](baseline/README.md) | Baseline design; boots from SD/MMC. HPS uses DDR5; HBM2E is not enabled. |
