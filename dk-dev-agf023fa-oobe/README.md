# Agilex 7 FPGA F-Series Development Kit - 2F Tile Crypto (DK-DEV-AGF023FA)

Platform folder `dk-dev-agf023fa-oobe` contains designs for the Agilex 7 FPGA F-Series Development Kit (2x F-Tile) DK-DEV-AGF023FA.

Refer to the [HPS Baseline System Example Design User Guide: Agilex 7 F-Series FPGA Development Kit](https://altera-fpga.github.io/latest/embedded-designs/agilex-7/f-series/fpga/gsrd/ug-gsrd-agx7f-fpga/) for more information.

## Designs

| Design | Description |
|--------|-------------|
| [baseline](baseline/README.md) | Baseline design; boots from SD/MMC. HPS EMIF ECC is enabled by default. |
