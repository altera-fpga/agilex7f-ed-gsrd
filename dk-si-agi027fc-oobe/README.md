# Agilex 7 FPGA I-Series Transceiver-SoC Development Kit (DK-SI-AGI027FC)

Platform folder `dk-si-agi027fc-oobe` contains designs for the Agilex 7 FPGA I-Series Transceiver-SoC Development Kit 4xF-Tile DK-SI-AGI027FC.

Refer to the [HPS Baseline System Example Design User Guide: Agilex 7 I-Series SoC Development Kit](https://altera-fpga.github.io/latest/embedded-designs/agilex-7/i-series/soc/gsrd/ug-gsrd-agx7i-soc/) for more information.

## Designs

| Design | Description |
|--------|-------------|
| [baseline](baseline/README.md) | Baseline design; boots from SD/MMC. HPS EMIF ECC is enabled by default. |
