# Agilex 7 FPGA F-Series Transceiver-SoC Development Kit (DK-SI-AGF014EB) — HPS NAND

Platform folder `dk-si-agf014eb-nand` contains designs for the Agilex 7 FPGA F-Series Transceiver-SoC Development Kit (DK-SI-AGF014EB) with the HPS NAND daughter card.

Refer to the [HPS Baseline System Example Design User Guide: Agilex 7 F-Series SoC Development Kit](https://altera-fpga.github.io/latest/embedded-designs/agilex-7/f-series/soc/gsrd/ug-gsrd-agx7f-soc/) for more information.

## Designs

| Design | Description |
|--------|-------------|
| [baseline](baseline/README.md) | Baseline design; boots from NAND. HPS EMIF ECC is enabled by default. |
